TRADUÇÃO PT-BR — PATHOLOGIC 3
=============================

Tradução e localização não oficial para português brasileiro.
63.703 falas — o jogo inteiro.


COMO INSTALAR
-------------
1. Feche o jogo, se estiver aberto.
2. Dê dois cliques em  Instalar-Traducao-PTBR.exe
3. Confira se a pasta do jogo que ele mostrou está certa. Se não achou
   sozinho, clique em "Procurar" e aponte a pasta que contém
   Pathologic3_Data.
4. Clique em "Instalar tradução" e espere.

Não precisa instalar Python nem nada: está tudo dentro do programa.

A instalação leva alguns minutos. Ela reescreve um arquivo de 780 MB do
jogo, então a barra fica um bom tempo na última etapa — é normal, não
travou. Antes de mexer em qualquer coisa o programa guarda uma cópia de
segurança.


PARA DESINSTALAR
----------------
Abra o programa de novo e clique em "Restaurar o original".

Isso devolve o arquivo original, guardado como resources.assets.bak dentro
da pasta do jogo.

Se o backup tiver se perdido, o Steam resolve:
   Biblioteca > clique direito no jogo > Propriedades >
   Arquivos Instalados > Verificar integridade dos arquivos


SE O ANTIVÍRUS RECLAMAR
-----------------------
Pode acontecer. Programas feitos assim (Python empacotado num .exe) são
confundidos com frequência, mesmo sem nada de errado — é falso positivo.

Se você preferir não liberar no antivírus, use o método manual, que está
na pasta "modo-manual":

   1. Instale o Python 3:  https://www.python.org/downloads/
      (marque "Add Python to PATH" durante a instalação)
   2. Abra o Prompt de Comando e rode:  pip install UnityPy
   3. Entre na pasta "modo-manual" e rode:
         python aplicar_traducao.py
      Para desfazer:
         python aplicar_traducao.py --restaurar


AVISOS
------
- Uma atualização do jogo sobrescreve a tradução. É só rodar de novo.
- Se o jogo atualizar e mudar os textos, o programa avisa que nenhum texto
  foi trocado e não altera nada.
- Jogue com backup do save, por precaução.


O QUE OLHAR DURANTE O TESTE
---------------------------
O que mais ajuda não é erro de português — é o que a tela mostra:

- texto cortado ou estourando a caixa de diálogo
- botão com texto que não cabe
- fala que parece fora de lugar na conversa
- nome de personagem ou lugar que muda de uma cena para outra
- qualquer coisa que soe traduzida em vez de escrita em português

Vale atenção especial aos INTERROGATÓRIOS e às ENTREVISTAS DO HOSPITAL:
é a parte mais recente da tradução e a que menos foi vista.

Anote o momento (dia do jogo, personagem, cena) — com isso dá para achar
a linha exata.
